# Normal Dev Guy: Inside Kenney World — Press Kit

Site oficial de divulgação (*press kit*) do jogo **Normal Dev Guy: Inside Kenney World**, um platformer 2D em pixel art disponível para PC via Steam.

🔗 Repositório: [normaldevguy](https://github.com/LeandroRogalaBritez/normaldevguy)

## 🎮 Sobre o jogo

**Normal Dev Guy: Inside Kenney World** é um platformer indie 2D onde um desenvolvedor de jogos pula para dentro da própria criação e precisa corrigir bugs jogando minigames caóticos a partir de dentro do código.

| Ficha técnica | |
|---|---|
| **Desenvolvedor/Publisher** | Leandro Rogala Britez Ltda |
| **Gênero** | Aventura / Casual / Indie / Platformer 2D |
| **Plataforma** | PC — Windows 10+ |
| **Modo** | Singleplayer |
| **Armazenamento** | ~400 MB |
| **Suporte a controle** | Sim |
| **Recursos Steam** | Conquistas, Cloud Save, Leaderboards, Family Sharing |

## 🌐 Sobre este site

Este repositório contém a landing page/press kit usada para divulgar o jogo antes e depois do lançamento, com seções de:

- **Sobre** o jogo
- **Fact Sheet** (ficha técnica)
- **Features** (diferenciais)
- **História**
- **Mídia** (vídeos/imagens de gameplay)
- **Contato**
- **Press Kit** para imprensa

O site é **bilíngue (EN/PT)**, com troca de idioma via botões no menu, usando um sistema de internacionalização próprio.

## 🛠️ Tecnologias

- HTML5 + CSS3
- JavaScript puro (sistema de i18n em `i18n.js`)
- Sem frameworks — site estático, leve e sem dependências de build
